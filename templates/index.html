How to explain it (30 seconds)

“The host (CPU, Python) never does the maths. It mallocs on the device, copies H2D, fires kernel<<<grid,block>>> so thousands of threads run at once, syncs, then copies D2H. The pink/green/yellow bar above is that story in milliseconds. Small N is launch-overhead bound — big N is where the device wins.”
